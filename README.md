# Unity Create with Code - Challenge 1: Plane

Unity公式ラーニングコース **「Create with Code」** の **Unit 1「Challenge 1（飛行機ゲーム）」** の課題実装リポジトリです。

## 🎯 概要
このチャレンジでは、飛行機を操作して浮遊させ、カメラで追いかけながら、プロペラを回転させる基本的なスクリプトの実装とパラメータ調整を行いました。

## ✨ 実装・対応内容
- **飛行機の移動（PlayerControllerX.cs）**
  - 上下キーや入力を受け取り、飛行機がスムーズに前進・上下に傾く挙動を実装
- **カメラの追従（FollowPlayerX.cs）**
  - プレイヤー（飛行機）の動きに合わせてカメラが追従する仕組みを調整
- **プロペラの回転（SpinPropellerX.cs）**
  - プロペラが一定の軸（Z軸）で高速回転するアニメーション・スクリプトを実装

## 🛠️ 開発環境
- **Engine**: Unity 6
- **Language**: C#
- **Version Control**: Git / GitHub
